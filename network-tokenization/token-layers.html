How the layers are created

PAR: one value per card

The Payment Account Reference (PAR) is the same for the card number and every network token of that card. It lets Geidea link payments made with the card number and with a network token to one card, without storing the card number. PGW copies it to paymentAccountReference on every transaction where the gateway returns it, on card-number payments too (NT-M2, NT-C2).

Dummy PARs on these pages: Visa V0010000000000000000000000001, Mastercard 5001TESTPAR000000000000000002.

An analogy

Card numberThe house key. Whoever copies it can open the door anywhere.
Geidea tokenThe ticket the merchant gets at the key desk. Useless outside Geidea.
Gateway tokenThe gateway's locker number for the key. MPGS uses Geidea's ticket number as the locker number; CyberSource gives its own number (the instrument identifier).
Network tokenA copy of the key, cut by Visa or Mastercard, that only opens this door for this merchant. Each use needs a one-time code (the cryptogram). Visa charges a fee when the house key is used instead.
