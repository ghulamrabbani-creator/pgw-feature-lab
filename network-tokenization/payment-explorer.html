Pick a gateway, a card, the switches and the saved card's state. The sequence shows each call between the merchant, PGW, the gateway and the scheme, what changes for PGW, and how the payment goes to the scheme: with the network token or with the card number.

Terms. Geidea token = the tokenId the merchant holds. Gateway token = MPGS token (MPGS) or instrument identifier, II (CyberSource). Network token = the token Visa (VTS) or Mastercard (MDES) issues for the card; the gateway sends it with a cryptogram. PGW never sees the full network token or the cryptogram. CIT = customer-initiated, MIT = merchant-initiated payment with a saved card. All identifiers are dummy values. Token layers explains the layers.
